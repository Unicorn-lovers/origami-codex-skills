# 基本形を折る手順

一辺を 1 とし、展開図の面を手前にして、左上から時計回りに A=(0,0)、B=(1,0)、C=(1,1)、D=(0,1) と呼ぶ。中心は O、辺 AB の中点は「AB の中点」と表す。山と谷は最初に手前にした面から見た向き。予備折りを開いてから形をつぶすと、途中で使った折り筋が最終状態では平らに戻ることがある。

## Preliminary base（正方基本形）

1. 左右の辺を合わせて谷折りし、開く。上下の辺も同様にする。二本の中心線の交点が O。
2. A と C を通る対角線を山折りして開く。谷の中心線二本と、この山の対角線一本を使う。
3. 紙を少し浮かせ、二本の谷折りを同時に閉じる。A、B、C、D を同じ位置に集めながら A–O–C を山に保ち、左右のひだを二枚ずつに分けて平らに押す。
4. 一辺が元の半分の正方形になる。四隅が重なる開いた端と、その対角にある閉じた端 O の距離は約 0.7071。開いた端から一枚ずつめくれることを確認する。

## Waterbomb base（風船の基本形）

1. 二本の対角線をそれぞれ谷折りして開く。左辺と右辺の中点を結ぶ横の中心線を山折りして開く。
2. 辺 AB を手元に置く。左右の辺の中点を互いに近づけ、O から両側に延びる山の折り筋をたたむ。AB 側と CD 側の三角の面が重なるまで閉じる。
3. AB が長さ 1 の底辺、O が頂点の二等辺直角三角形になる。A の位置に D、B の位置に C が重なり、底辺の両端に二枚ずつ角がある。

## Blintz base（座布団の基本形）

1. 対角線の交点 O を軽くつまんで印にする。紙を裏返し、O が分かるように置く。
2. 一つの角を O にぴったり合わせ、隣り合う二辺の中点を結ぶ線で折る。残りの三つの角も、一枚ずつ同じ面で O に合わせる。元の展開図の面から見ると四本とも山折りになる。
3. 中央で会う四つの先端を別々に持ち上げられる。外周は四辺の中点を頂点とする正方形で、その対角線の長さは元の一辺と等しい。

## Fish base（魚の基本形）

1. A–C を長軸として、対角線に目印をつけて開く。A の位置を保ったまま辺 AB を A–C に合わせ、折り筋をつけて開く。C を保ったまま辺 CB も C–A に合わせて開く。二本の折り筋は B 側の点 P=(1−r,r) で交わる。ここで r=1−1/√2（約 0.2929）。
2. A–P と C–P の二本を谷に閉じ合わせながら、B–P を山につまんで B を耳状に立てる。P から右辺 BC まで横に延びる谷折りを使って耳を片側に倒す。長軸 A–C は広げたままにする。
3. 対角線の反対側で、辺 AD と CD をそれぞれ A–C に合わせて折り筋をつける。交点 Q=(r,1−r) で D–Q を山につまむ。こちらの耳は Q から辺 CD まで**縦**に延びる谷折りに沿って倒す。この最後の折り筋の選択が同梱 CP の向きを決める。
4. A と C は √2 離れた長軸の両端に残る。B と D の耳先は別々の紙片だが、真上から見た位置は一致する。

## Bird base（鶴の基本形）

1. 正方基本形の手順で四隅を集める。この CP では最終的な A–O–C が谷になるので、出発時は正方基本形の山谷をすべて逆にする。O を上、四隅の集まる開口を下にしてひし形に置く。B と D が手前と奥の一枚になるようにページを配置する。
2. 一番手前の一枚だけを使う。下の角から延びる左右の縁をそれぞれひし形の縦軸に合わせ、根元にできた二つの折り端を結ぶ横線にも印をつける。一度開く。
3. 手前の下端一枚をつまみ、横線を軸に上へ持ち上げる。左右の縁を先ほどの折り筋で中央へ寄せ、細いひし形に平らにする。模型を左右に裏返し、奥にあった一枚にも同じ花弁折りを行う。
4. 長い軸の一端に A と C、他端に B と D が重なる。両端間は 1。展開すると辺 AB の内側の折り線が (0.5,(√2−1)/2) で交わり、その 90° 回転位置にも同じ交点が現れる。

## Frog base（かえるの基本形）

1. A–O–C が山になる向きで正方基本形を作り、O を上、四隅が集まる開口を下にする。
2. 右のひだを一枚起こす。その二層の間に指を入れ、袋の背の折り筋を模型の中心線に重ね、袋の左右を均等に押し開いてつぶす。済んだ面を本のページのようにめくり、残り三つの袋もそれぞれつぶす。
3. つぶした一面を正面に置く。手前の袋の口の左右の斜辺を縦軸へ寄せて折り筋をつけ、開く。袋の口の先端一枚を左右の肩を結ぶ線で持ち上げ、両側を折り筋に沿って内側に戻して花弁折りにする。ページをめくり、四面すべてで繰り返す。
4. 四隅由来の長い先端を同じ側にそろえる。正面から見て長い先端から O までは約 0.7071。一方、辺の中点四つはその軸に沿って長い先端から 0.5 の位置で重なる。向きに迷う場合は展開して確かめる。辺 AB の中点から内側へ約 0.14645 の箇所で、中心線の山谷が切り替わる。

## Kite base（凧の基本形）

1. A–C の対角線を折って開き、長軸の目印にする。A を手元に向ける。
2. A を動かさずに辺 AB を長軸へ重ねて谷折りする。折り筋は A から辺 BC 上の (1,√2−1) に届く。
3. 辺 AD も A を軸にして同じ長軸に合わせる。B と D が一枚ずつ中央に来て重なる。重なった先端は A から 1、C から約 0.4142 の位置にある。A と C の間隔は元の対角線の長さ √2。

## Windmill base（風車の基本形）

1. 四辺の四分の一の位置を目印にして、中央に一辺 0.5 の正方形を取る。左上隅を P=(0.25,0.25) とする。中央正方形の四辺に谷の折り筋をつける。
2. P と A を結ぶ線に谷、P と辺 DA の中点を結ぶ線に山の折り筋をつける。紙を 90° 回して同じ操作を繰り返す。元の向きでは、右上の隅からは B へ谷、辺 AB の中点へ山が延びる。四隅まで一周する。
3. 中央の正方形を机に置き、周囲の帯を立てる。四辺の中点を O へ寄せながら、隅ごとに谷と山をつまみ、元の紙の角を外へ倒す。左上では A が元の辺 DA の中点の位置に向かう。残りも同じ回転方向に倒し、中央を平らにする。
4. A、B、C、D は四枚の羽根の外端に残り、それぞれ O から 0.5 離れる。中心に来るのは元の四辺の中点。対向する二枚の羽根の先端間隔は 1。

## 改造後の折り順

基本形から引き継ぐ最後の手順を選び、そこから変更対象のひだを開ける段階まで戻る。例えば座布団の角一枚を解放するなら、手順 2 でその角だけ残し、他の三隅が O に着くことを確かめる。耳を分ける設計なら、耳の折り筋をどの段階で付け、どの層をつまむかを追加する。

[照合用の目印と距離](../assets/sequences/landmarks.json)は、元の片面図における平坦な折り上がりの値。これらの手順の実紙試験は未実施。改造で移動する先端や新しい層の重なりは、改造した CP とその折り順で確認する。
