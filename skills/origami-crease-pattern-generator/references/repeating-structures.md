# 繰り返しのある折り紙を設計する

同じ線が並んでいても、設計で決める寸法は作品によって異なる。ひねり模様なら隣の中心までの距離、蛇腹の器なら断面の半径、ユニット折り紙なら差し込みの形が、隣り合う部分を作図する手掛かりになる。

## ひねり折りのテセレーション

まず完成時の模様をタイルの隣接図として描く。各タイルに中心の多角形、表裏、ひねる向きを記し、タイル間には共有するひだの幅と、中心間で進む格子の歩数を入れる。三角格子と正方格子では使える方向が違うため、両方の格子を重ねて近似する前に、模様に必要な方向を選ぶ。

1. ひとつの中心から出るひだを立て、中心をひねって平らにする。中心の多角形の縁が下地の格子線から外れる場合がある。その縁が実際にどこに生じるかを開いて確かめる。
2. ひだをひとつ延ばして隣の中心まで折る。単純なひねり同士を一本のひだでつなぐ構成では、同じ側から見てひねりの向きが逆になる。隣を描く際は、表から見た回転と、裏返して観察した回転を区別する。
3. 繰り返しの継ぎ目をまたぐ範囲を試す。中心だけでなく、両側の山谷線が同じ位置を通り、同じ幅で次の区画に入るかを見る。格子点に端点が載っていても幅や層がずれたら、まず中心間隔かひねりの種類を直す。縁まで反復したら、端で切れる中心やひだの収め方も決める。

写真を手掛かりにする場合、表の三角形のすき間が、裏側では開いたひねりの中心になることがある。見えている多角形だけを写すと、単位同士がどうつながるかが消えてしまう。表と裏を同じ向きに対応づけ、仮説が複数あれば継ぎ目を含む見本片で比べる。

敷石のように表の多角形が隣接する模様では、完成図で見えなくなる帯にも紙幅が要る。多角形の間に二重のひだを収める帯を描き、一周して最初の頂点に戻れるか確認する。一つの頂点で決めた帯幅が次の頂点の残り幅を拘束する。すべてを独立に調整すると、見た目がそろっても展開図が閉じない。

**凹凸でドット絵を見せる場合。** 二種類の単位を同じ寸法で作り、表に小さな四角い面が現れる状態と、裏側にひねりを収めて表にはひだの交点が現れる状態を割り当てる方法がある。画素の数と各単位を作るのに必要な格子数は別に数える。隣り合う同種・異種の単位で、裏のひだが収まり、表の差が見分けられるかを試す。表裏の色そのものを指定されたドット絵には[可視色を照合する探索](pixel-art.md)を使い、凹凸や照明による陰影は色の一致判定に含めない。

## 蛇腹で器の輪郭を出す

回転対称の器を平行な帯で作る場合は、横から見た外形を先に描く。この方法は直線のひだと位置の変わるひだを対にして、各高さで周方向に露出する長さを変える。正方形一枚、接着なしなどの指定があれば、最初に底と継ぎ目をその条件で作れるか確かめる。

- 側面の輪郭に半径と高さの組 `(r, z)` を取る。最大半径を `R`、一周の帯数を `N` とすると、帯幅の初期値は `w ≈ 2πR/N`。帯数は曲面の滑らかさと、一つのひだを指で扱える幅との兼ね合いで決める。重ね継ぎを使う設計では、その分の紙を別に足す。
- 紙の縦方向の位置には、輪郭に沿った区間長 `√(Δr² + Δz²)` を順に足す。口と底の高低差だけで紙丈を決めると、ふくらみの分が不足する。
- 帯の中心線から片側へ `(w/2) × r/R` だけずらした点に、曲がる側の折り線を通す。反対の折り線群は直線のまま保つ。この作り方では、半径0で折り線が帯の中央へ、最大半径で端へ来る。例えば帯幅12 mmのとき、最大半径の半分の断面では中央から3 mmずれる。
- 数本の帯で、底・最大径・口に対応する断面を折り比べる。くびれや水平に近い輪郭でひだが追従しない場合は、その部分を緩くする。曲面の保持や自立は立体の試作で確かめる。平坦に畳む計算だけで判定すると、狙った器の形を評価できない。

断面を編集できるように採寸点と曲線を残す。直線しか持てない `.cp` に書き出す場合は、曲線を複数の線分で近似したことを記録する。作図上の線分の継ぎ目に、実物でも鋭い折れが必要かどうかは別に確かめる。

## ユニットの結合部を作る

複数枚を使う指定なら、完成品のどの辺・面・頂点を一枚が担うかを決める。例えば一枚が一辺を担う構成の枚数は辺の数になる。同じ立体でも、一枚が一面を担う構成にこの枚数は使えない。

試作は隣り合う二枚から始める。差し込み片の向き・幅・長さと、受けポケットの開口・奥行き・止まる位置を対応させる。次に一頂点と、その隣の面まで組み、接合を重ねても最後の差し込み口が開けられるか調べる。表面の装飾を変えるときは、この接合部を保てば複数案を同じ骨組みで比べられる。

本体と接続用の部品を別に折る方式では、それぞれの用紙寸法・枚数を記す。鏡写しの二種類を交互に組む案なら、左右を各一枚ずつ折って差し込みの向きと表の縞のつながりを一度に試す。ロックが抜ける場合は、ポケットの奥行きか差し込み片の長さを変え、同じ紙厚で一頂点をもう一度組む。細い辺が曲がったり、層が多くて入らない場合もあるため、寸法の変更は小さな接合試験で判断する。

最後の一枚が入らないときは、輪が閉じるひと手前に戻る。隣の接合を一つ開けて最後の差し込み片を先に通す案と、最後に閉じる辺を移す案を比べる。どちらも手が届かない場合は、ポケットの入口や差し込み方向を変えて小さな閉ループを試す。つり下げ用のひもなどを内側に固定する設計では、最後のロックを閉じる前に取り付ける。

色指定がある場合は、ユニットが占める辺または面に色を置き、隣接関係をいったん平面図で解く。色ごとの枚数が合っても、巻き方向を逆にした箇所で数手後に同色が接することがある。一頂点から隣の面までの仮組みが配色図と一致してから反復する。成果物には各種類のユニットの展開図と、その差し込み先を示す組立図を添える。
